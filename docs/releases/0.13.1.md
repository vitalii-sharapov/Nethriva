## VMware console security fix

Older VMware servers can identify their console certificate with a SHA-1 fingerprint. In 0.13.0, that fingerprint alone could make Nethriva accept the certificate. SHA-1 is too weak to use as the sole check.

In 0.13.1, Nethriva can still verify the console using a SHA-256 fingerprint or a full certificate provided by VMware. If the ticket supplies only SHA-1, the app asks macOS to verify the certificate and confirm that it matches the console hostname before sending the console ticket. If macOS already trusts the server, the console opens normally. If a legacy console shows a certificate error after updating, ask your VMware administrator to configure a certificate trusted by macOS for the console hostname.

## Installation

Requires an Apple silicon Mac with macOS 14 or later. Open the DMG and drag Nethriva into Applications, or extract the ZIP. Both downloads contain the compiled app and have SHA-256 checksum files on the [release page](https://github.com/vitalii-sharapov/Nethriva/releases/tag/v0.13.1). The app is locally signed and has no Apple notarization. If macOS asks for approval, review the download before approving it in System Settings.
